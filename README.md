# 抖音搜索增强 DouyinSearchPlus

抖音网页版浏览器插件（Chrome / Edge，MV3）。v0.5.0

v0.5 新增：
- **博主主页模式**：进入任意博主主页（作品/喜欢标签页），工具条自动出现，
  排序、组合排序、阈值筛选、角标、黑马标记、自动加载、CSV 导出全部可用。
  换博主自动清零重新统计；主页导出的 CSV 文件名自动带博主昵称

v0.4 新增：
- **互动率排序**：藏赞比（干货度）、评赞比（互动度）两个新维度，可参与组合排序
- **黑马标记**：🔥 = 发布≤30天且日均点赞进当前结果前10%（正在起飞）；
  💎 = 藏赞比进前10%且点赞≥100（干货密度高）。角标自动显示
- **导出 CSV**：一键导出已捕获结果（标题/作者/发布时间/四维数据/比率/黑马/链接），
  Excel 直接打开无乱码

- **搜索结果排序**：按 点赞 / 评论 / 收藏 / 分享 从多到少重排瀑布流（再点一次取消）。
  **支持多选组合**：同时点亮多个维度时，按"各维度名次之和"排序
  （用名次而不是数值相加，避免十万级的点赞数淹没百级的评论数），名次和小的排前面
- **阈值筛选**：只看 赞≥N / 评≥N / 藏≥N 的结果
- **与官方筛选自由组合**：官方的发布时间/时长/排序依据是服务端筛选（决定返回哪些结果），
  插件是客户端加工（对已返回的结果再排序/再筛），两者串联生效；
  切换官方筛选时插件自动清空重新统计（识别接口里的 filter_selected 参数）
- **评论区按点赞排序**：一键把评论按点赞数从多到少排列
- **自动加载**：自动下拉加载搜索结果（上限300条）/ 评论（上限1000条）
- **数据角标**：搜索卡片左上角显示 赞/评/藏（官方只显示点赞）

界面是页面底部一条深色胶囊工具条，按当前页面自动出现/隐藏对应按钮；
点"—"收起成右下角小圆点。

原理：被动监听页面自己发出的接口响应拿数据，自己重算瀑布流坐标来排序，
不主动发任何请求，不碰账号风控。

## 安装

1. Chrome 地址栏输入 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本文件夹 `douyin-search-plus`
4. 刷新抖音页面，搜索时页面底部出现工具条即成功

## 使用

- **搜索页**：搜索关键词 → 底部工具条点 点赞/评论/收藏/分享 即排序，再点一次恢复。
  建议先点"加载更多"攒够样本再排（排序只针对已加载的结果）。
  "筛选"里可设阈值和角标开关。
- **视频页**：评论区出现后，点"按赞排序"；想排完整先点"加载全部"。

## 实测记录（2026-07，改版排查用）

| 项目 | 实测值 |
|---|---|
| 搜索接口 | `/aweme/v1/web/general/search/stream/`（曾用名 search/single） |
| 官方筛选参数 | 同一接口的 `filter_selected={"sort_type":"2","publish_time":"7"}` + `is_filter_search=1`，服务端过滤 |
| 主页作品接口 | `/aweme/v1/web/aweme/post/`（喜欢是 `/aweme/favorite/`），带 `sec_user_id`，返回 `aweme_list`，未登录 403 |
| 主页卡片 | `[data-e2e="user-post-list"]` 内 `ul[data-e2e="scroll-list"] > li > a[href*=/video/]`，正常文档流，用 CSS order 排 |
| 评论接口 | `/aweme/v1/web/comment/list/`（reply 是楼中楼，已排除） |
| 搜索卡片 | `div#waterfall_item_<视频ID>`，绝对定位瀑布流，transform 摆位 |
| 瀑布流参数 | 3列 x=13/258/503，卡宽220，纵向间距25（代码里动态反推，不写死） |
| 评论列表 | `[data-e2e="comment-list"]` 直接子级=评论包装div，正常文档流 |
| 评论点赞数 | 评论内第一个"旁边带SVG图标"的纯数字文本；正文数字（QQ号）无图标 |

## 失效排查

1. 控制台（F12）执行 `localStorage.DSP_DEBUG = '1'`，刷新
2. 操作一遍，把 `[DSP]` 日志发给 Claude
3. 常见修复点：
   - 接口路径 → `src/inject-main.js` 的 `classify()`
   - 卡片标识 → `src/content.js` 的 `search.cards()`（`waterfall_item_` 前缀）
   - 评论选择器 → `commentSort.rows()`（`data-e2e` 属性）
4. 改完在 `chrome://extensions/` 点插件刷新按钮，再刷新抖音
