# 真机验证清单（约 10 分钟）

本地仿真站（`test/sim`）只能复刻"结构契约"。下面这些事实只能在真实抖音上确认。每次抖音改版、或大版本发布前，按清单走一遍，结果写回 `test/sim` 的仿真页和本文件。

前提：已登录抖音；先**不要**点"继续加载"，全部手动操作；插件已在 `chrome://extensions/` 点过刷新，抖音页面也刷新过。

## 搜索页（/search/关键词?type=video）

- [ ] 工具栏出现在结果上方，状态句显示"已读取 20 条"左右
- [ ] 卡片上出现收藏率标签，数字和点开视频后看到的收藏 ÷ 点赞一致
- [ ] 手动滚到底，翻页后条数增加（说明接口拦截正常）
- [ ] 连续翻到 100 条以上，第一张卡仍在页面里（确认没有虚拟滚动；如果有，原地排序要改走兜底视图）
- [ ] 点一次"继续加载"，观察是否能自动翻页（程序滚动能否触发抖音翻页）
- [ ] 先选"真需求"排好序，再点"继续加载"，仍能翻页，新读到的作品直接排进名次
- [ ] 在精选首页顶部搜索（地址是 /jingxuan/search/…），工具栏照常出现
- [ ] 「综合」标签：卡片上有收藏率；点「排序」提示切到「视频」，点「切到视频」能切过去并正常排序
- [ ] 切换官方"筛选 → 发布时间：一周内"，插件条数重新计数
- [ ] 按收藏率排序 → 恢复原顺序，页面完全还原、控制台无报错

## 字段核对

- [ ] 插件的"转发"数 = 视频页右侧"分享"图标下的数（确认 share_count 对应"转发"）
- [ ] 合集卡（左上角"合集"）的数据属于这条视频本身，而不是整个合集
- [ ] 广告卡、直播卡、用户卡没有被计入

## 博主主页（/user/…）

- [ ] 首屏约 18~20 条有数据（服务端直出，靠 fiber）
- [ ] "置顶"作品能被识别并可排除
- [ ] 账号 Top10 预设的结果，与按"收藏名次 + 评论名次"手算一致
- [ ] 切到"喜欢"标签，数据不和"作品"混在一起
- [ ] 选"账号 Top10"后点"继续加载"，能一直读到作品总数（状态句"已读取 N / 总数"）
- [ ] 排好序后拖动窗口变窄 / 变宽，卡片列数跟着变、没有横向滚动条
- [ ] 从一个博主主页点到另一个博主主页，详情卡里"占账号总获赞"按新博主的获赞算

## 视频页 / 弹层（/video/… 或 ?modal_id=…）

- [ ] 评论按赞排序、按回复排序都生效，还原后顺序正确
- [ ] 评论项上能读到 cid 和点赞（看元素上有没有 `data-dsp-cid`）；没有也能靠接口配对
- [ ] 在搜索页点开视频弹层，插件工具栏不遮挡播放器控件
- [ ] 评论区顶部显示这条视频的收藏率，和视频下方 ♥ / ★ 的数字算出来一致
- [ ] **新开无痕窗口、直接粘贴一条视频链接打开**，评论区顶部仍显示收藏率（验证详情接口 `aweme/detail` 或详情区 fiber 至少一条能读到；都读不到时只显示提示语）
- [ ] 弹层里评论没几条时点"加载全部"，背后的搜索结果不跟着翻页
- [ ] 在评论区点"加入候选"，回到搜索页复制入库包，里面有"评论区"和"原评论"

## 扩展弹窗

- [ ] 在抖音搜索页点浏览器右上角的插件图标，弹窗显示"搜索结果页 · 已读取 N 条"（不是"当前页面不是抖音网页版"）
- [ ] 刚装好或刚更新插件、抖音页还没刷新时点图标，弹窗提示"刷新一下抖音页面"
- [ ] 在别的网站点图标，弹窗提示去抖音

## 滚动方式

- [ ] 选"真需求"后第 1 名自动滚到工具栏下面；继续加载读完后自动回到第 1 名
- [ ] 在收藏率标签上按 ↑ 跳到上一名，聚焦的卡片不被工具栏挡住
- [ ] 视频页评论"按回复"排好再点"加载全部"，读完后回到回复最多的那条
