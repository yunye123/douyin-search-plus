# 商店上架材料

建议渠道顺序：**Microsoft Edge 加载项商店**（国内可直接访问、开发者注册免费，Chrome 用户也能装 Edge 版）→ Chrome 应用商店 → GitHub Release（zip）。
开发者账号注册、身份验证、提交审核需要作者本人操作；下面是可以直接复制的材料。

## 名称

抖音搜索增强 DouyinSearchPlus

> 名称里出现"抖音"有被认为冒用商标的风险。如果审核要求修改，备选：「选题雷达 · 抖音网页版选题助手（非官方）」。

## 简短描述（≤132 字）

找抖音爆款选题。基础筛选：点赞、评论、收藏、时长；进阶筛选：收藏率（收藏÷点赞，80%以上当真需求）、日均赞、评论率、转发率、最新发布、有门槛。看中的标星存档。免登录，数据只在本机。Chrome / Edge 加载已解压扩展。

## 详细描述

找抖音爆款选题。

排序分两段。基础筛选：点赞、评论、收藏、视频时长，点一下就排，可以换方向。进阶筛选：收藏率（收藏 ÷ 点赞，80% 以上当真需求）、日均赞、评论率、转发率、最新发布、有门槛，以及其余看法和组合排序。

看中的视频标星存档。

免登录。用 Chrome 或 Edge 加载已解压的扩展程序安装。插件自己不向任何服务器上传或收集数据。候选篮封面会按已保存的图片地址加载；其余数据只在本机。

本插件为开源工具，非抖音官方产品，与北京字节跳动科技有限公司无关。

## 单一用途说明

在抖音网页版用基础筛选（点赞、评论、收藏、视频时长）和进阶筛选（收藏率（收藏 ÷ 点赞，80% 以上当真需求）、日均赞、评论率、转发率、最新发布、有门槛）筛选，并把看中的视频标星存档。

## 权限理由

| 权限 | 理由 |
|---|---|
| 在 `https://www.douyin.com/*` 上运行内容脚本 | 读取页面已加载的作品与评论数据，并在页面上显示收藏率、排序和工具栏 |
| 主机权限 `https://www.douyin.com/*`（与内容脚本同一网址，不增加安装提示） | 点开扩展弹窗时识别当前标签页是不是抖音网页版，显示这一页的读取状态；页面还没加载插件时提示"刷新一下页面" |
| `storage` | 在本机保存用户设置（开关、角标、加载上限）、候选篮、最近读到过的 300 条作品的公开数据，以及复制过的作品 id（防止重复入库） |
